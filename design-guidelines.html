Design system

Design guidelines

How we make Creative Digital Company feel unmistakably itself — the tokens, components, and accessibility baseline behind every page we ship. This page is the living reference for the design system: brand identity, color, type, spacing, motion, and reusable UI.

See the site

01 · Brand

Brand identity

Creative Digital Company — a design and development studio. The wordmark is CDC., always set with the terminal accent dot. Our tagline: "We build brands and digital products people remember."

Logo assets

  • Light surface

    Use logo-wordmark.svg on light backgrounds. Clearance of one stroke height on all sides; minimum width 140px.

  • Dark surface

    Use logo-wordmark-inverse.svg on dark backgrounds. Never place an ink logo on ink, or a light logo on white.

  • Mark

    The C with a terminal dot is our mark. Minimum size 24px; don't rotate, recolor the dot away from the accent, or add effects.

04 · Space

Spacing, radii, shadows

A 4px-based spacing scale is the single source of truth — no stray rem values in components. Radii keep the current site radius (14px) as the default card radius.

Token Value Use
--space-1 … --space-16 0.25rem → 8rem All margins and padding
--radius-sm / md / lg / xl / full 8 / 14 / 20 / 28px · full Inputs · cards · surfaces · pills
--shadow-sm / md / lg theme-aware Elevation
--shadow-accent coral glow Primary button hover

05 · Motion

Motion

Micro-interactions run at 100ms, standard transitions at 200ms, and nothing essential exceeds 500ms. Under prefers-reduced-motion: reduce all non-essential animation is disabled (WCAG 2.3.3).

  • --duration-fast 100ms · hover states, focus flicks
  • --duration-base 200ms · transitions, toggles
  • --duration-slow 500ms · reserved, large surfaces only
  • --ease-out cubic-bezier(0.22, 1, 0.36, 1) · entrances
  • --ease-in-out cubic-bezier(0.65, 0, 0.35, 1) · exits

06 · Components

Component library

Reusable, accessible UI lives in src/components/ and consumes design tokens only. Use the component classes in new markup — never hand-roll styles that duplicate them.

Component Class Notes
Button .cdc-button Navigation uses <a>, actions use <button>
Card .cdc-card Interactive cards expose a real link — no click handlers on the card
Form .cdc-field Labeled controls, error text bound via aria-describedby
Nav .cdc-nav One primary landmark; footer nav carries a distinct label
Footer .cdc-footer Body-level footer maps to the contentinfo landmark

07 · Accessibility

Accessibility baseline (WCAG 2.1 AA)

  • All text pairings meet AA (≥ 4.5:1); body and muted text are AAA in both themes.
  • Focus is always visible: --color-focus outline with offset, and :focus-within on interactive cards.
  • Color is never the only channel for state — pair with a glyph or label.
  • Touch targets are ≥ 44×44px; text links ≥ 24px.
  • Skip link, landmark nav, one h1 per page, and labeled form controls are required on every page.
  • The automated a11y lint in test/a11y-components.test.js enforces this baseline in CI.
